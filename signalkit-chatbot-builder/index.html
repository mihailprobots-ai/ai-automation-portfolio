The assignment asks for a landing page and a clickable app prototype. This version connects both into one onboarding path, so a visitor understands the value before entering the builder.

Core idea

Teams already have answers scattered across PDFs, Notion pages, pricing docs and help articles. SignalKit turns that knowledge into a branded assistant, then gives the team a safe place to test answers before publishing the widget.
